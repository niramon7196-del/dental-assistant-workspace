## 1) Google — #BuildHybridAI 2026

รางวัลรวม 30,000 ดอลลาร์ และมีโอกาสถูกนำเสนอโดยทีม Firebase

สิ่งที่ต้องส่งตามอีเมลของ Devpost
- [ ] เลือกแพลตฟอร์มอย่างน้อย 1 อย่าง: **Web (Chrome) ใช้ Gemini Nano** / Android / iOS (Apple Foundation Models) → โปรเจกต์นี้เป็นเว็บ จึงเลือก Web (Chrome)
- [ ] คำอธิบายข้อความ: ใช้ Firebase AI Logic อย่างไร คุณสมบัติ ฟังก์ชัน และคุณค่าที่นำเสนอ
- [ ] repo สาธารณะ GitHub/GitLab มีไฟล์ license ที่มองเห็นชัด (มี MIT แล้ว) มีทุกอย่างที่จำเป็นให้รันโปรเจกต์ได้ และ **มีโค้ดที่เรียก Firebase AI Logic จริงใน repo**
- [ ] วิดีโอ ≤ 3 นาที โชว์การทำงานบนแพลตฟอร์ม เผยแพร่บน YouTube เสียงอังกฤษหรือมีคำบรรยายอังกฤษ
- [ ] เพราะเป็นแอปที่มีอยู่แล้ว: สรุปสิ่งที่สร้าง **ในช่วงเวลาการแข่งขัน** และคุณค่าหลักของแอปเดิม
- [ ] (แนะนำ) URL ที่โฮสต์ไว้
- [ ] ระบบ AI ทั้งหมดต้องทำงานผ่าน Firebase AI Logic และต้องมี App Check (debug token ใช้ได้)

สถานะ: เขียนโค้ด Firebase AI Logic + App Check + โหมด Hybrid แล้ว (ฟีเจอร์ร่างคำตอบแชต) **แต่ยังไม่ได้ทดสอบกับ SDK จริง** ต้อง `npm install`, ลงทะเบียน debug token และทดสอบบน Chrome เดสก์ท็อปก่อนถ่ายวิดีโอ
ข้อควรระวัง: Gemini Nano บน Web ใช้ได้เฉพาะ Chrome บนเดสก์ท็อป ถ่ายวิดีโอเดโมบนเดสก์ท็อปไม่ใช่ iPad

โครงวิดีโอ 3 นาที
1. 0:00–0:20 ปัญหาหน้าเก้าอี้ทำฟัน (1 สถานการณ์จริง)
2. 0:20–1:10 แปลภาษาข้างเก้าอี้ พร้อมป้าย On-Device / Cloud
3. 1:10–1:50 คิว → จอทีวี + เสียงเรียก
4. 1:50–2:25 AI Inbox → ร่างงาน → ผู้ใช้ยืนยัน
5. 2:25–3:00 on-device ทำงานอย่างไร เมื่อไรถอยไป cloud และสิ่งที่สร้างในช่วงแข่งขัน

## 2) RPU New CreatorsX 2026 (มหาวิทยาลัยราชพฤกษ์)

- [ ] หนังสือยืนยันความเป็นเจ้าของผลงาน (PDF) — ประเภทนวัตกรรม/สิ่งประดิษฐ์/งานสร้างสรรค์
- [ ] รูปผลงาน 3–5 ภาพ (JPG/PNG)

- [ ] หนังสือยืนยันเจ้าของผลงานสร้างสรรค์ด้วย Generative AI + หลักฐานกระบวนการทำงาน (ประวัติ prompt, ภาพร่าง หรือคลิปบันทึกหน้าจอ) ต้องใช้ **ถ้าส่วนใดของงานสร้างด้วย Gen AI** — ควรเตรียมไว้เพราะโปรเจกต์พัฒนาด้วย AI ช่วยเขียนโค้ด

ร่างเนื้อหา Concept paper (ใช้ได้เมื่อกรอกข้อมูลจริงแล้ว ต้องไม่เกิน 1 หน้า)
