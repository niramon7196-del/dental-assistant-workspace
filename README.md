# AI Dental Assistant Workspace

An all-in-one clinical productivity and patient communication workspace built specifically for daily dental clinic operations, combining real-time Firebase backend services with Google Gemini hybrid AI capabilities.

## Key Features

- **Dual-Space Clinical Workflow:** Seamless switching between chairside clinical operations, patient queue tracking, and waiting-room TV display modes.
- **Multilingual AI Voice & Translation Assistant:** Real-time interactive voice assistance with persistent Thai translation transcripts to bridge communication barriers with international patients during dental procedures.
- **Smart Inventory & Stock Management:** Multi-column dental supply inventory tracker with inline editing and low-stock monitoring.
- **Automated Patient Follow-Up & Satisfaction Tracking:** Streamlined post-treatment follow-up workflows and patient satisfaction survey logging.
- **Lightweight Crystal-Glass UI:** Optimized for fast, low-power rendering on iPads and mobile devices in clinical environments.

## Architecture & Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend & Security:** Firebase (Firestore, Hosting, Firebase App Check)
- **Hybrid AI Integration:** Google Gemini API (`firebase/ai`) for clinical task assistance, real-time translation, and workflow intelligence
